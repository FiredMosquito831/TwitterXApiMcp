One registry, every surface

Every operation is defined once with a zod schema. The CLI, the MCP server and the SDK are projections of the same definition.

✎

Create, edit, delete, thread, poll, quote reads, hide replies, repost. Media upload with alt text and chunked video.

Built for restraint

The unofficial transport uses your logged-in browser session against private endpoints. X prohibits this and may permanently suspend the account. It is off by default and every action requires an explicit confirmation.

Install in one command

Node.js 24 or newer. The npm package bundles every JavaScript dependency.

npm

npm install -g x-mcp-automation
xctl setup

Bins: xctl, xctl-mcp, and the aliases x, x-mcp.

npx, no global install

npx -y x-mcp-automation setup

The Claude Code plugin ships its own server bundle.

PyPI / pipx

pipx install x-mcp-automation
xctl setup

A launcher; Node.js 24 is still required.

Agents and scopes

Install for every agent found on PATH, or choose targets and a scope.

xctl install all
xctl install all --scope project
xctl install codex opencode
xctl uninstall all

Claude Code and Codex support global and project scopes. opencode writes JSON config. Antigravity is global only.

Guardrails, not promises

  • Spend cap. XCTL_SPEND_CAP (default $5) refuses operations that would cross it. Link posts are priced at $0.20, not $0.015, before they run.
  • No bulk actions. There is no like-many, follow-all or keyword auto-reply. One target per invocation by design.
  • Confirmations. Writes are marked destructive and non-idempotent. Unofficial actions need an explicit flag every time.
  • Credentials. OAuth 2.0 PKCE with refresh rotation, stored in the OS keychain, with a user-scoped file fallback.
  • Rate limits. Buckets are seeded from X's own headers and persisted per profile, not guessed.
